# Vehicle Logistics Management System

A CLI-based Vehicle Logistics Management System developed using C++ to manage vehicles, cities, routes, bookings, and trip scheduling.

## Features

- Vehicle Registration and Management
- View, Search, Update and Delete Vehicles
- Vehicle Maintenance and Servicing
- City Management
- Automatic Route Generation
- Booking Management
- Automatic Booking ID Generation
- Trip Scheduling
- Automatic Trip ID Generation
- Vehicle Availability Management
- File-Based Data Persistence

## Technologies Used

- C++
- Object-Oriented Programming
- STL (Standard Template Library)
- File Handling
- Visual Studio
- Command Line Interface (CLI)

## Project Modules

- Vehicle Management
- City Management
- Route Management
- Booking Management
- Trip Scheduling
- Data Management

## Project Overview

This project was developed as a practical C++ application to understand and implement real-world logistics management concepts through a command-line interface.

It focuses on modular programming, object-oriented concepts, data handling, file persistence, and management of vehicles and trips.
